# Sounds

Add your audio files here using these exact names. The site works without them. Missing files are skipped silently.

| File | Used for |
| --- | --- |
| `startup.mp3` | Clicking the start button on the home page |
| `click.mp3` | Buttons |
| `nav.mp3` | Navigation links |
| `menu-open.mp3` | Opening the mobile menu |
| `menu-close.mp3` | Closing the mobile menu |

Tips:
- Use MP3 for the widest browser support.
- Keep each sound short (under about one second for clicks) and quiet.
- Only use sounds you created or have the license to use.
- To rename a file, edit the `sounds` block in `js/config.js`.
